# MK.HUB 통합 디자인 패치: 적용 및 검증 가이드

## 적용 대상과 목적

이 패치는 제공된 `mk.hub-main` 소스를 기준으로 작성한 **11개 파일 변경**입니다. 기존 Firebase 데이터 흐름, 비밀번호 해제 상태, IndexedDB 사진 키, iframe 높이 통신, 갤러리별 고유 레이아웃, 절대음감 트레이너의 3층 스크롤 구조를 유지하면서, MK.HUB 전반에 어두운 무채색 기반과 코랄 포인트의 통합 레이어를 추가합니다.

| 영역 | 변경 파일 | 핵심 결과 |
|---|---|---|
| 허브·내부 페이지 | `index.html` | 토큰 확장, 카드 깊이, 포커스 링, 메모·파일·할 일의 로딩·빈 상태, 갤러리 테마 동기화, 음악 오버레이 전환 |
| 갤러리 01~05 | `1picture.html`~`5picture.html` | 기존 사진 키·편집 잠금·높이 통신을 건드리지 않는 공유 상호작용 브리지 |
| 새 공용 모듈 | `gallery-motion.js` | `mk_theme` 메시지 수신, IntersectionObserver 기반 reveal, 데스크톱 hover·터치 active 상태 |
| 절대음감 트레이너 | `pitch-trainer.html` | 다크 토큰 통일, 카드 깊이, 명확한 키보드 포커스, 감속 모드 |
| 명언 | `quotes.html` | 97개 원문 데이터를 유지한 에디토리얼 카드 그리드와 첫 카드 히어로 구성 |
| 코드 사전 | `chord-dictionary.html` | 허브 팔레트 연결, 카드·입력 포커스와 hover 계층 정리 |
| 코드 에디터 | `code-editor.html` | 허브 팔레트 연결, 에디터 포커스 바, 미리보기·저장 목록 깊이 보강 |

## 적용 방법

프로젝트 루트, 즉 `index.html`이 있는 폴더에 패치 파일을 둔 다음 아래 명령을 실행합니다. 패치는 표준 unified diff 형식이며 `patch -p1` 기준으로 경로가 정규화되어 있습니다.

```bash
patch -p1 < MK_HUB_통합_디자인.patch
```

변경 전 상태를 확인하려면 먼저 dry run을 실행하십시오.

```bash
patch --dry-run -p1 < MK_HUB_통합_디자인.patch
```

> 패치는 제공된 압축본의 파일 내용과 일치하는 버전을 기준으로 생성되었습니다. 소스가 별도로 변경되었다면 dry run 후 충돌 난 hunk만 원본 주변 문맥에 맞춰 수동 반영해야 합니다.

## 보존한 계약

| 계약 | 보존 방식 |
|---|---|
| 사진 영속성 | 기존 `MKPics` 호출 및 키 규칙(`p1:s*`, `p2:*`, `p3:img-*`, `p4:img-*`, `p5:cell-*`)을 변경하지 않았습니다. |
| 편집 권한 | 각 갤러리의 `mk_unlock` 수신과 동일 오리진 검사를 그대로 둡니다. 새 모듈은 잠금 상태를 읽거나 우회하지 않습니다. |
| iframe 높이 | 기존 `iframe_height`, `lt_height`, 프레임 ID 및 `ResizeObserver` 코드를 수정하지 않았습니다. |
| 레이아웃 고정 요소 | `2picture.html`의 `transform:scale(0.9)`와 `5picture.html`의 직접 스크롤 구조를 유지했습니다. |
| 앱 동작 | Firebase CRUD, PIN, 음악 재생, 코드 실행, 절대음감 오디오, 페이지 히스토리를 재작성하지 않고 스타일과 표시 레이어만 추가했습니다. |
| 성능·접근성 | `prefers-reduced-motion`에서 새 모션을 사실상 비활성화하고, 포커스 가능한 컨트롤에 가시적 포커스 링을 보강했습니다. |

## 검증 완료 항목

패치 파일은 원본 소스의 깨끗한 복제본에 `patch --dry-run -p1` 및 실제 `patch -p1`로 적용을 확인했습니다. 적용 후 `gallery-motion.js` 생성, `index.html`의 디자인 브리지, 갤러리 초기화 코드, 절대음감 테마 브리지 존재를 확인했습니다. 또한 새 공용 모듈은 `node --check`를 통과했습니다.

다음 브라우저 수동 검증을 권장합니다.

| 시나리오 | 기대 결과 |
|---|---|
| 다크·라이트 전환 | 허브 색상과 다섯 갤러리의 상호작용 외곽선 색상이 함께 변경됩니다. |
| 갤러리 잠금 상태 | 해제 전에는 기존과 동일하게 편집 버튼과 이미지 교체가 비활성 상태입니다. |
| 갤러리 사진 교체 | 각 갤러리의 기존 이미지를 변경·새로고침했을 때 사진이 그대로 복원됩니다. |
| 메모·파일 폴더 | 네트워크 대기 중 스켈레톤, 데이터 없음 시 명확한 빈 상태, 데이터 존재 시 기존 카드 렌더링이 표시됩니다. |
| 음악 도구 | 절대음감·코드 사전 진입과 닫기 시 페이드 전환이 보이며, 뒤로가기와 오디오 동작은 기존과 같습니다. |
| 모바일·감속 모드 | 모바일 1열/기존 iframe 높이 동작을 유지하고, 감속 모드에서는 장식 애니메이션이 정지합니다. |

## 포함하지 않은 변경

이미지 URL 교체, 명언 데이터 수정, Firebase 스키마 변경, 인증 정책 변경, 외부 API 추가, iframe 샌드박스 완화, 프레임워크 전환은 포함하지 않았습니다. 따라서 이 패치는 디자인·상호작용 계층의 **최소 침습적 변경**입니다.
