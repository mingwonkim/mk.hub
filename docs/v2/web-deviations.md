# 설계 변경 근거

## 도시 스틸 2차
- 사용자 피드백에 따라 중앙 저층 항로 대신 수 km 높이에서 내려다보는 도시 협곡 구도로 변경. 1차 대칭 전경 건물·단순 곡면·추상 천 광고판은 폐기 대상으로 기록.
- 이미지 모델은 초기 nano_banana_pro에서 Higgsfield gpt_image_2 / high / 4k로 변경. 실제 catalog 확인 후 선택했으며 high가 해당 모델 최고 품질 설정. 초기 모델의 요청/반환명 불일치와 더 높은 세부 묘사 요구 반영.
- 검토는 생성 원본으로 진행. 웹용 300KB 이하 압축본은 전달 최적화용이며 화질 판단 근거로 삼지 않는다. 원본을 별도로 보존한다.
- 도시 스틸 한 장에 대한 사용자 확인 전 영상·추가 공간·UI 구현을 진행하지 않는다.
