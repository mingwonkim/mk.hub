# MK.HUB 웹 설계 초안

설계: gpt-6-astra/high, collaboration /root/city_design (초반 1회). 아래는 설계 결과의 정리본. 현재 사용자 검토용 제작물은 도시 스틸 1장뿐; 나머지 UI·영상은 후속 계획이다. PRD와 템플릿 기반이며 전체 레퍼런스 영상 실측 전.

## 1. IA와 공간
Hub에서 Vault·Music·Morning Brief·Todo·Gallery·Settings로 이동. Vault는 개인 사무실, Music은 소속사 작곡실, Brief는 드론 배달, Todo는 글래스 시점, Gallery는 전시관. 기존 files→memo와 저장 구조 유지.
1440: 12열/최대1280/좌우48/간격24; 1024: 8열/좌우32/간격20; 768: 4열/좌우24/간격16; 390: 단일열/좌우16. 도시 배경 전체화면, 작업 영역은 내부 그리드.

## 2. 화면 구성
도시 중앙에 전진 가능한 항로. 어두운 전경 건축물 → 밝은 전광판·비행선 → 마천루·흰 안개·핑크 구름. 왼쪽 아래에는 낮은 복잡도 여백. 스틸에 UI·버튼·로고를 굽지 않는다.
후속 공통 UI: 내비64, 패널 여백24, 제목28, 본문16, 보조14, 입력/주요버튼44. 검색·목록·편집·저장상태·모달·잠금을 같은 규칙으로.
Vault: 폴더224+목록300+편집, 1024에서 폴더 접기. Hub 최근자료/할일 두열. Music 기존 도구, Todo 캘린더/선택일 목록, Brief 전달 후 본문, Gallery 큰 교체형 사진 중심. Gallery 상세 배치는 lowtheory 전체 확인 후 구체화.
목록 로딩/빈상태/오류/선택, 편집 변경됨/저장중/저장됨/실패. 실패 시 입력 보존.

## 3. 브랜드
배경 #090D16, 불투명 표면 #161E2A, 글자 #F4F6FA, 보조 #B8C4D8, 핑크 #F2AACB, 포커스 #A9DDF3.
Astra 제안 대비(불투명 표면 기준): 주15.49:1/보조9.52:1/핑크9.09:1. 실제 기본 유리 상태 대비는 구현 시 별도 검증.
유리 rgba(22,30,42,.90)는 출발값; hover/focus-within/입력중 불투명. 터치는 불투명 우선. 색감은 어두운 도시+밝은 피사체+흰 안개+핑크 구름이며 균일 네온야경·세피아 제외.
기존 글꼴 우선 확인, 시스템 한글 sans-serif 폴백. 크기14/16/20/28/48, 본문행간1.6, 패널반경16/입력10, 그림자 0 16px 48px #00000040. AI 취향은 격자, 의류는 에디토리얼 구성, 작곡은 스튜디오.

## 4. 모션
첫 접근8초, 반복/섹션이동3~5초를 검토 초안으로 제안. 매번 출발·이동·도착 전체 경로를 보여주며 시간만 짧게. 패널 열린 뒤 카메라 정지.
패널 opacity0→1/translateY12→0, 240ms cubic-bezier(.22,1,.36,1); 유리160ms ease-out; 포커스 즉시.
시간 기반 이동과 일반 콘텐츠 스크롤을 분리하는 안을 Astra가 제안. 사용자 인트로 상호작용 요구와 스킬의 스크롤 시킹 방식은 영상 단계에서 비교 검토; 아직 확정 아님.
건너뛰기·reduced-motion·정지대체 지원. 제목은 도착 후 표시.

## 5. 에셋
현재 nano_banana_pro/2k/16:9 스틸1장. 실제 확인 모델. 승인 전 추가 이미지·영상 금지.
후속 kling3_0/pro: 3~15초, start_image/end_image, sound off. 건물·카메라방향·빛을 공유하고 승인된 이미지로 연결.
Astra 원안 전달용량 제안은 이미지500KB/영상8MB. 이번 전달본은 스킬 기준 이미지300KB 이하/영상3MB 이하를 우선 목표로 하며 상세품질은 보존 원본으로 검토. 영상 품질과 용량 상충은 해당 단계에서 기록.
현재 견적 nano_banana_pro 2k 1장=2 credits exact. 잔액263.5, 사용자 총사용상한 해제, 자동구매 미승인.

## 6. 기술
기존 정적 index.html SPA/GitHub Pages 유지. Expo/React 추가하지 않는다. CSS와 video로 시작. 실시간 포인터/깊이 상호작용은 필요 시 웹 코드로 추가하며 AI영상 자체가 자유시점3D라는 주장은 하지 않는다.
setPage/doOpenApp 진입을 대조해 장면전환 연결. Firebase 경로/MKVault/소유자규칙/음악iframe/갤러리키 유지. 운영자료로 프리뷰 채우지 않는다.
포스터 우선, 영상 지연 로드, 동시재생1개, 실패해도 저장소 접근. LCP2.5초 초기 목표는 실제 측정 필요. 키보드·포커스복귀·44px 조작·저장상태 안내 확인.

## 7. 단위와 완료 기준
현재: 비용확인→도시스틸1장→도시규모/명암/항로 확인→기록→사용자확인에서 정지.
후속: 도시영상→확인→Vault스틸→확인→연결영상→확인→유리패널1개→확인→기능별확장.
1440x900/1024x768/390 반응형, 기본/hover/편집 가독성, 저장재접속·사진교체·잠금·음악 회귀검증.
